# Kerem Barbaros Karnabat - Portfolio 🚀

Welcome to the repository for my personal developer portfolio, hosted on GitHub Pages and accessible via [cadakerem.me](https://cadakerem.me).

## 🛠 Tech Stack
This portfolio is built with performance, smooth animations, and a modern aesthetic in mind.
- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [React Icons (Fa)](https://react-icons.github.io/react-icons/)
- **Deployment:** GitHub Pages (via `gh-pages` branch)

## 📁 Project Structure
- `src/components/Hero.tsx`: Introduction and social links.
- `src/components/About.tsx`: Background and workflow overview.
- `src/components/Projects.tsx`: Featured projects (ReviewForge, Coffin Clash, Agentic Vault, etc.).
- `src/components/Skills.tsx`: Categorized tech stack & tools (Unity, Python, C#, etc.).

## 🚀 Running Locally
If you want to run this project on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/cadakerem/cadakerem.github.io.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🔒 Security & Privacy
This repository contains purely static frontend code. There are no backend integrations, API keys, databases, or environment variables (`.env`) included in this project. Everything is 100% safe to be open-source.
