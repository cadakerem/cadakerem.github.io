## 🚀 Başlangıç
Bu proje **Vite + React (TypeScript)** şablonu kullanılarak oluşturulmuş ve doğrudan GitHub Pages'e deploy edilecek şekilde önceden yapılandırılmıştır.

### Kurulum
```bash
# Bağımlılıkları yükle
npm install

# Geliştirici sunucusunu başlat
npm run dev
```

## 🌐 GitHub Pages'e Deploy (Canlı Yayın)
Projenizin `package.json` ve `vite.config.ts` dosyaları halihazırda yayın yapmaya hazırdır. 
Projenizi canlıya almak için tek yapmanız gereken:

```bash
npm run deploy
```
*Not: GitHub üzerinden reponuzun "Pages" ayarlarından `gh-pages` branch'inin seçili olduğundan emin olun.*
